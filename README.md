# websites

Small static websites, in one repo.

Folders:
- `astroworld/` — AstroWorld website, folded in from the former AstroWorldHome repo.
- `faith-mbc/` — Faith Missionary Baptist Church website, folded in from the former FaithMBC repo.
- `pritchett-info/` — Austin Pritchett professional site, live at https://www.pritchett.info (Cloudflare Pages; bare pritchett.info redirects to www). Includes headshot and November 2026 resume PDF.
